Project Viva Q&A & Defense Cheatsheet

            
Ready answers for your project review and teacher questions

          

        

        
      


      

        

          
          

            

              Q1. "Where will registration and user data save?"
            

            

              Answer to tell teacher: "In Phase 1, data is stored client-side in the browser's persistent LocalStorage & IndexedDB engine in structured JSON format with cryptographic password hashing. When deployed to production, it maps directly to our relational SQL database schema (PostgreSQL/MySQL) with a dedicated users table, articles table, and bookmarks table. You can inspect this live right now by clicking the Database & Storage Inspector button!"
            

          


          

            

              Q2. "What are the 5 modules of your project?"
            

            

              Answer:
              
1. Module 1: Authentication & User Profiles (User registration with validation, password strength meter, persistent session tokens, and scholar profiles).
              
2. Module 2: Category & Topic Discovery Engine (Academic category taxonomy, real-time zero-latency search engine, auto-suggestions, and match highlighting).
              
3. Module 3: Information Display Module (Presents detailed content of a selected topic or category in a clean, readable format with structured headings, typography scaling, supporting imagery, dynamic Table of Contents, and Web Speech API text-to-speech audio reader).
              
4. Module 4: Content Management Module (CMS) (Handles the addition, editing, and deletion of information within the platform without directly modifying underlying code).
              
5. Module 5: User & Admin Management Module (RBAC) (Manages role-based access control, distinguishing regular users who search/browse from administrators who have authorized access to modify content).
            

          


          

            

              Q3. "How does the search and category filtering work?"
            

            

              Answer: "The search engine indexes titles, summaries, tags, and body content dynamically. As the user types, it performs real-time multi-field text matching, keyword highlighting with regular expressions, and category slug filtering simultaneously with zero latency."
